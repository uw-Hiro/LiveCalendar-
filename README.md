# ライブ検索 (Live Search)

指定した日付に開催されるライブ・コンサート情報をサクッと検索できる、シンプルなウェブアプリケーションです。

## アプリの概要
HTML、CSS、JavaScriptのみで構築された軽量なツールです。
カレンダーから日付を選択して「検索する」ボタンを押すだけで、その日にライブを行うアーティスト名と会場名が即座に表示されます。
UVERworldなど、自分が参戦する予定のバンドのスケジュールを自分用にまとめる第一歩として最適な構成になっています。

## 機能
- **日付検索:** カレンダー入力（`<input type="date">`）を使って直感的に日付を指定可能。
- **瞬時な結果表示:** 条件に一致するアーティスト（例: UVERworld、SUPER BEAVER など）と会場名をリストアップ。
- **該当なし表示:** 指定した日付に登録されたライブがない場合は「情報がありません」と分かりやすく案内。

## 開発環境
- HTML
- CSS
- JavaScript

※ 外部ライブラリやサーバーは不要で、ブラウザだけで動きます。

## 使い方
1. このリポジトリから `.html` ファイルをダウンロードします。
2. ダウンロードしたファイルをダブルクリックし、お使いのブラウザ（ChromeやEdgeなど）で開きます。
3. 画面の「日付を選択：」から検索したい日（例: `2026-02-03`）を選びます。
4. 「検索する」ボタンを押すと、結果が表示されます。

## データの追加・編集方法
今後のライブ予定を追加したい場合は、ファイル内の `<script>` タグにある `liveData` というリストを直接編集します。

```javascript
// この部分に新しい予定を追加できます
const liveData = [
    { date: "2026-01-23", artist: "Kroi", venue: "国立代々木競技場 第一体育館" },
    { date: "2026-02-03", artist: "UVERworld", venue: "KT Zepp Yokohama" },
    // 追加例: { date: "YYYY-MM-DD", artist: "アーティスト名", venue: "会場名" }
];
